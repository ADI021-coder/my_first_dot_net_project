# Age Progression Calculator (C#)

A simple C# console application that calculates a user's future age and equivalent age in months based on current input.

## Features
- Accepts user input via the console
- Converts string input to numeric types
- Performs arithmetic calculations
- Outputs formatted results

## Concepts Used
- Variables and data types
- Type conversion (`Convert.ToInt32`)
- Arithmetic operations
- Console input/output

## How to Run
1. Clone the repository
2. Run the program using a C# compiler or `.NET` environment
